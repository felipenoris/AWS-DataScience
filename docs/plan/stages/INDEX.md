# Stages — index

Dependency order, not importance. Open one stage file plus the decisions its `Consumes` row lists;
that is the whole reading list for executing it.

A stage's status is written in its own file. The header's `Status` row holds what is done and what is
owed, each with its date, and the stage log holds what ran: the same slug under
[`docs/log/`](../../log/INDEX.md), prefixed `log-`. The **State** column below is one word, changed when
a stage opens or closes. The position of every open stage in one line, with what comes next, is
`CLAUDE.md`'s Current position.
